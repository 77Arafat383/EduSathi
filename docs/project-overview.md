# EduSathi: Project Overview

## 1. Project Title
**EduSathi: AI-Powered Smart Learning Management System**

## 2. Problem Statement
Educational activities are often fragmented across disparate platforms and manual tools:
- Learning materials are distributed in unmanaged folders or external cloud drives.
- Homework and assignment submissions are collected through disparate communication channels.
- Gradebook evaluations are maintained in siloed spreadsheets.
- Attendance is recorded on paper registers with limited longitudinal visibility for students.
- Academic doubt resolution is separated from lesson content.
- Students lack automated, curriculum-grounded study recommendations.

## 3. Project Objectives
1. Provide a unified full-stack application connecting Students, Teachers, and Administrators.
2. Deliver responsive role-specific dashboards with actual database records.
3. Support multiple-choice quiz creation with tamper-proof server-side scoring.
4. Support assignment submission, teacher grading, score bounding, and feedback release.
5. Provide a 365-day annual attendance heatmap grid for student engagement tracking.
6. Integrate an AI study assistant providing concept explanations, revision schedules, and practice questions with transparent fallback.
7. Protect accounts and academic data with server-side authorization (RBAC) and BOLA checks.
8. Deliver exhaustive technical documentation, database migrations, testing evidence, and security audit reports.

## 4. Target User Personas
- **Students**: Learn from courses, complete interactive quizzes, submit assignments, view released grades, monitor 365-day attendance, and ask the AI study assistant for revision plans.
- **Teachers**: Author courses and lessons, build multiple-choice quizzes, evaluate submissions, release grades with pedagogical feedback, and record daily session attendance.
- **Administrators**: Provision accounts, manage role permissions, oversee courses and subjects, and inspect institutional analytics.
