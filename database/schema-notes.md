# EduSathi Database Schema Notes

## 1. Overview
EduSathi uses a relational PostgreSQL schema (with Supabase compatibility) designed for high integrity, normalized entities, strict role-based access, and fast query execution.

## 2. Table Relationships Summary

- **Profiles**: Core user registry (`student`, `teacher`, `admin`). Authenticated users reference this table.
- **Subjects & Courses**: One-to-many relationship between Subjects and Courses. A course is authored by a user and can have multiple co-teachers via `course_teachers`.
- **Enrollments**: Bridge table connecting `profiles(student)` to `courses`. Unique constraint prevents duplicate active enrollments.
- **Modules & Lessons**: Hierarchical structure (`course -> modules -> lessons`).
- **Lesson Progress**: Tracks completion per student per lesson with timestamps.
- **Quizzes & Questions & Options**: Quizzes contain questions with type (`single` or `multiple`). Options store answer choices and explanations. Correct answers are hidden from students until results are released.
- **Quiz Attempts & Answers**: Captures student attempts, server-calculated scores, and individual question choices.
- **Assignments & Submissions & Grades**: Assignments define instructions and due dates. Submissions store student responses. Grades store score, teacher feedback, and release timestamp.
- **Attendance Sessions & Records**: Tracks daily/session course attendance with statuses `present`, `absent`, `late`. Provides the underlying data for student annual attendance heatmaps.
- **Announcements & Notifications**: In-app notifications and course broadcast announcements.
- **Comments**: Discussion threads linked to courses, assignments, or quizzes to resolve student doubts.
- **Study Plans & Tasks**: Student revision goals and schedule tasks generated by or aligned with the AI study assistant.

## 3. Row-Level Security (RLS) & Access Controls
- Students can only view their own submissions, grades, attendance records, and notifications.
- Teachers can only view and evaluate submissions and record attendance for courses they teach.
- Admins possess system-wide oversight for accounts and subjects.
- Sensitive credentials and correct quiz keys are never transmitted to unauthorized users.
